## About

A simple number guessing game made with Python.

The computer generates a random number between the initial and final values entered by the user. The player keeps guessing until they find the correct number.

## How to Run

Run `code.py` using Python 3.

## Features

- Random number generation
- High/low hints
- Keeps asking for guesses until the correct number is found
